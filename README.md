# 🍽️ Global Zomato Restaurant Analytics

## 📌 Project Overview

This project performs Exploratory Data Analysis (EDA) on the Zomato Restaurant Dataset along with Country Code data to uncover insights about restaurant trends, cuisines, ratings, pricing, and customer preferences across different countries.

The goal is to transform raw restaurant data into meaningful business insights through data cleaning, analysis, and visualization using Python.
---

## 🎯 Objectives

- Analyze restaurant distribution across countries and cities.
- Identify the most popular cuisines.
- Understand customer rating patterns.
- Explore the impact of online delivery and table booking services.
- Analyze restaurant price ranges and affordability.
- Generate actionable insights through visualizations.
